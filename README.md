# ✨ Deleted Messages TG Bot

Telegram-бот, который незаметно сохраняет все сообщения в личных чатах и
позволяет просматривать историю изменений и удалённые сообщения.

## 🔥 Возможности

* Просмотр удалённых сообщений (текст)
* Просмотр истории изменённых сообщений
* Простая установка и настройка
* Поддержка современного и быстрого пакетного менеджера `uv`

> Ниже инструкция для быстрого запуска локально на Вашем устройстве.

### 🚀 Быстрый старт:

1. `git clone https://github.com/abamka2004/deleted-messages-tg-bot.git`
2. `cd deleted-messages-tg-bot`
3. `cp .env-example .env` - а вот здесь немного задержимся.

Нужно получить `TOKEN` у [BotFather'а](https://t.me/BotFather). Создаёте бота,
копируете его токен и вставляете в соответствующее поле в `.env`.

Ваш USER_ID можете взять из любого бота, я пользуюсь
[@UserInfoToBot](https://t.me/UserInfoToBot). Фух, продолжим.

4. `pip install uv`
5. `uv sync`
6. `uv run python -m src.main`
7. Готово, бот запущен! Дальнейшие инструкции найдёте в самом боте по команде /start
